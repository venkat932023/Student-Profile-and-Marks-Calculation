# Student Profile and Marks Calculator

## <strong>Project Overview</strong>

The **Student Profile and Marks Calculator** is a simple JavaScript-based mini project that collects student details and subject marks from the user and calculates the **total marks, average marks, and next year's age**.

This project is designed to practice fundamental **HTML and JavaScript concepts**, including variables, user input, type conversion, arithmetic operations, and template literals.

## <strong>Features</strong>

* <strong>Student Profile</strong> – Collects the student's name, city, and age.
* <strong>Marks Input</strong> – Accepts marks for three subjects.
* <strong>Total Marks</strong> – Calculates the total marks obtained.
* <strong>Average Marks</strong> – Calculates the average of three subjects.
* <strong>Age Calculation</strong> – Calculates the student's age for the next year.
* <strong>Result Display</strong> – Displays the complete student profile using an alert box.

## <strong>Technologies Used</strong>

* <strong>HTML5</strong>
* <strong>JavaScript</strong>

## <strong>JavaScript Concepts Used</strong>

* <strong>Variables</strong> using `let`
* <strong>User Input</strong> using `prompt()`
* <strong>Type Conversion</strong> using `Number()`
* <strong>Arithmetic Operators</strong>
* <strong>Template Literals</strong> using backticks
* <strong>String Formatting</strong> using `toFixed()`
* <strong>Alert Messages</strong> using `alert()`

## <strong>How It Works</strong>

1. The user enters their <strong>name</strong>.
2. The user enters their <strong>city</strong>.
3. The user enters their <strong>age</strong>.
4. The user enters marks for <strong>three subjects</strong>.
5. The program calculates the <strong>total marks</strong>.
6. The program calculates the <strong>average marks</strong>.
7. The program calculates the <strong>next year's age</strong>.
8. The final student profile and calculated results are displayed in an <strong>alert box</strong>.

## <strong>Formula</strong>

<strong>Total Marks:</strong>

```text
Total Marks = Subject 1 + Subject 2 + Subject 3
```

<strong>Average Marks:</strong>

```text
Average Marks = Total Marks / 3
```

<strong>Next Year's Age:</strong>

```text
Next Year's Age = Current Age + 1
```

## <strong>Example</strong>

If the user enters:

```text
Name: Reddy
City: Hyderabad
Age: 22

Subject 1: 80
Subject 2: 75
Subject 3: 90
```

The output will be:

```text
============== Student Profile ==============

Name: Reddy
City: Hyderabad
Age: 22

Subject 1: 80
Subject 2: 75
Subject 3: 90

Next Year's Age: 23
Total Marks: 245
Average Marks: 81.67
```

4. Enter the requested student information.
